# MV-CU060-10GC 软件触发网页采集

使用已安装的海康 MVS SDK，连接 `192.168.3.13`，按目标帧率发送 `TriggerSoftware` 命令，并在浏览器显示实时画面。网页可暂停、继续、单次触发，帧率可设为 1–20 FPS，还可切换相机自身的 1×、2×、4× Decimation。页面显示实际帧率、图像尺寸，以及相机图像流的实时接收带宽和占千兆网口的比例。

## 运行

```bash
cd /home/handong/Code/hik_cam
LD_LIBRARY_PATH=/opt/MVS/lib/64 python3 app.py --fps 5
```

浏览器打开 `http://127.0.0.1:8005`。按 `Ctrl+C` 停止程序。脚本默认使用本机已安装的 `/opt/MVS`，不需要 Flask 或 OpenCV。默认参数为 3072×2048、BayerRG8、曝光 10 ms、Decimation 1×。

可用 `--width`、`--height`、`--exposure-us` 调整采集区域和曝光时间，`--decimation 2` 可在启动时启用 2× 降采样。例如：

```bash
LD_LIBRARY_PATH=/opt/MVS/lib/64 python3 app.py --fps 20 --decimation 2
```

Decimation 由相机硬件完成。对默认全视场，实测 2× 时输出 1536×1024，单帧图像数据约为原来的 1/4；4× 时输出 768×512，约为原来的 1/16。页面带宽来自 MVS 的 `MV_GIGE_GetNetTransInfo` 接收字节统计，按最近约 2 秒计算，表示相机图像流而非整张网卡的所有流量。

降采样降低网口负载，但全视场的传感器读出仍可能限制帧率。此机在默认全视场、10 ms 曝光下，目标 20 FPS 时，2×/4× 降采样实测约 14–15 FPS。若需要接近 20 FPS，可以使用较小 ROI，例如 `--width 1280 --height 720 --decimation 1 --fps 20`。

如果希望同一局域网的其他设备访问，可加 `--host 0.0.0.0`，然后访问电脑的 IP 和端口 8005。也可通过 `--ip` 和 `--port` 修改相机地址及网页端口。

## 常见问题

- “打开相机失败”：先关闭 MVS 客户端或其他正在独占相机的程序。
- “未发现相机”：检查电脑相机网卡与 `192.168.3.13` 同网段，并用 MVS 客户端确认设备在线。
- 页面实际帧率低于目标值：检查曝光时间、相机最大帧率、网卡带宽和图像尺寸。

这里的“软件触发”是程序向相机发送软件命令。若要通过相机 IO 线接收电信号，需要切换 `TriggerSource` 到对应的 `Line`，并按相机接线图连接。
